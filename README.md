# PETROL

Статическая адаптивная посадочная страница по макету Figma. Все изображения и SVG хранятся локально в `assets/`; для шрифтов используются Unbounded и Onest через Google Fonts, с системными fallback-шрифтами.

## Запуск

Из папки проекта выполните:

```sh
python3 -m http.server 4173
```

Затем откройте `http://localhost:4173`.

## Интерактивность

- Навигация ведёт к секциям страницы; на узком экране она открывается кнопкой меню.
- Слайдер «Как это работает» переключается стрелками, индикаторами, клавишами ←/→ при фокусе на слайдере и свайпом на сенсорном экране.
- Контактная кнопка открывает письмо на `petrishev.danil@yandex.ru`.
- Анимации при прокрутке реализованы через WOW.js 1.2.2 (MIT, CDNJS); собственная анимация находится в `styles.css`. Если библиотека недоступна или включён `prefers-reduced-motion`, все блоки остаются видимыми.

## SEO перед публикацией

`robots.txt`, `sitemap.xml` и абсолютные URL в canonical, Open Graph и JSON-LD пока используют `https://example.com`. Перед публикацией замените его на фактический HTTPS-домен сайта во всех этих файлах и в `index.html`; XML-карта включает только главную страницу, так как это одностраничный сайт.
